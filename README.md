## Overview
This repository contains the practical works and assignments for the CSC426 Weekly Dev tasks. It currently includes a Python-based GUI Calculator and a PHP web-based authentication system.



Projects Included

1. GUI Calculator (`calculator.py`)
A simple, user-friendly graphical calculator built using Python and the `tkinter` library. It features a custom dark-mode UI and performs basic arithmetic operations.

* Features: Addition (`+`), Subtraction (`-`), Multiplication (`*`), Standard Division (`/`), Integer Division (`\`), Modulo (`%`), Exponentiation (`^`), and a Clear (`C`) function.
* Requirements: Python 3.x (Tkinter is included in the standard Python library).

2.Web-Based Login System (index.php)
A responsive, single-file authentication application built with HTML, CSS, and PHP. It handles both the frontend user interface and the backend logic, including form validation and dynamic success/error message rendering.

* Features: Input validation, secure credential verification logic, and responsive CSS styling.
